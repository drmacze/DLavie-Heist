# DLavie Heist — Canonical Project Scope

`drmacze/DLavie-Heist` is the canonical project for the DLavie gameplay modpack.

The cancelled CS2-ONLINE experiment is not part of the roadmap. Future development is tracked here and may include:

- Actual Guns 2 integration and weapon-system modifications
- DLavie Heist / vault gameplay
- squad spectator and grave-loot systems
- ragdoll physics
- gore / blood VFX
- parkour compatibility
- medical / ballistic / other survival systems used by the full DLavie suite

Actual Guns 2 remains the authoritative gun core. DLavie patches should preserve firing/reload/item identity unless a feature explicitly requires a targeted change.

The public repository source currently contains the editable Heist core and integration specifications. Full third-party vendor assets are not re-uploaded here; release builds are assembled from the supplied AG2/modpack inputs.
